Чтобы сохранить повторные наблюдения, прореживать нужно по постоянному идентификатору, а не по отдельным строкам. Один раз выбираешь клиентов или контракты — и сохраняешь все их даты.
Для твоей задачи предпочтительнее отбор по клиенту:
1. Берёшь уникальных клиентов за весь нужный период, включая январь и февраль.
2. Случайно выбираешь, например, 25% клиентов.
3. Забираешь все контракты этих клиентов на всех доступных датах.
4. Сохраняешь список выбранных ID, чтобы выборка воспроизводилась.

Построчный случайный отбор сам по себе не всегда неправильный. Для твоего повторного скоринга его недостаток — потеря повторных наблюдений, важных для соответствия обучающей выборки реальному применению модели.
