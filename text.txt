Коллеги, добрый день!

Запускаем ежедневный скоринг новых претензий LLM-классификатором.

Как работает

Раз в день обрабатываются претензии за вчера (report_date = сегодня − 1).
Результат пишется в одну общую таблицу Oracle: ema_complaints_classification.
Сейчас в проде первый продукт — Автокредит. Дальше буду добавлять остальные продукты по мере готовности таксономий и промптов.
Поля в таблице

Поле	Смысл
claim_num
номер претензии
created
дата создания претензии в Siebel
report_date
дата отчёта (за какой день скорили)
product / theme / category
продуктовые поля из источника
classifier_name
какой классификатор писал строку (например, auto_loan)
type
issue (проблема) или req_action (запрос клиента)
class / sub_class
класс и подкласс по таксономии
eval
1, если judge подтвердил и класс, и подкласс; иначе 0
Одна претензия может дать несколько строк (несколько issues / requested actions).

Прошу обратную связь Нам удобнее идти итеративно: сначала Автокредит в ежедневном контуре, затем подключать следующие продукты.
